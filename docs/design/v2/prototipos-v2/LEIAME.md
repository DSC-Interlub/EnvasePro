# Protótipos aprovados — direção "Fluxo" (EnvasePro 2.0)
Referência visual APROVADA pelo dono. Os arquivos são protótipos (formato do editor de design): leia o HTML/CSS/estilos como referência, não copie a estrutura.
Tokens: fundo #F3F4F8, cartão #fff raio 22-24, marca #3B5BFF (tom suave #EEF1FF/#E3E8FF), tinta #141A2B, texto fraco #7A8296, ok #12A66B, atenção #E69A00, erro #E5484D. Fonte Manrope 500-800, mono JetBrains Mono (códigos). Sombra: 0 1px 2px rgba(20,26,43,.05), 0 10px 30px rgba(20,26,43,.05). Hover de cartão: sobe 3-4px.
Todos os dados dos protótipos são de exemplo.

## Padrões para as demais telas (novos)
- Padrao-Lista.html: tela de lista (Registros, Produtos, Operadores, Notas...): cabeçalho com migalha + título + ações; chips de filtro com contagem; busca; tabela em cartão com ação que aparece no hover; rodapé de paginação.
- Padrao-Formulario.html: formulário (Novo produto, Nova NF, cadastros): seções em cartões numerados, campos cinza suave com halo no foco, seletor segmentado, chips de certificação, painel lateral "como vai aparecer" + salvar.
- Padrao-Modulo-Empilhadeira.html: módulo operacional (Empilhadeira, Check-out, Recebimento, Limpeza): KPIs, lista de cards de linha com progresso e status, linha do tempo de paradas, cartão de manutenção.
REGRA: toda tela do sistema deve seguir um destes padrões (ou Envase, Checklist, Painel, TV). Se a tela não encaixa, proponha ao dono antes.
